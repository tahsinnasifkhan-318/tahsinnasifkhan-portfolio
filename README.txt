TAHSIN NASIF KHAN — PORTFOLIO WEBSITE

Files:
- index.html: main portfolio website
- assets/: project evidence screenshots and demo presentation

Preview:
Double-click index.html to open it in your browser.

Publish/update with GitHub Pages:
1. Open your GitHub repository.
2. Open the repository's main page and choose Add file > Upload files.
3. Upload index.html and the complete assets folder (including its files).
4. Commit changes to the main branch.
5. Wait for GitHub Pages to redeploy, then refresh your website.

Important:
This website describes personal learning demonstrations, not deployed client systems.
The clothing-shop demo uses manual Google Sheets entry and human review. It does not
automatically read Facebook Messenger or send customer confirmations.
